## 🗝️ Fitur Utama

- 👾 **Retro Vibes** – Simulasi PC jadul booting ke terminal *nix, lalu menjalankan neofetch untuk menampilkan aktivitas GitHub.
- 🖼️ **Kreativitas Tanpa Batas** – Kendali penuh atas visual, profil GitHub jadi kanvas ekspresi.
- 📈 **Statistik GitHub Live** – Update otomatis pencapaian & kontribusi terbaru.
- 🎨 **Pilihan Skema Warna** – 10+ skema warna populer + dukungan penuh ANSI escape sequence.
- 🛠️ **Konfigurasi berbasis TOML** – Kustomisasi simulasi terminal jadi lebih rapi dan mudah.

## 🎯 Motivasi

- 🌈 **Kustomisasi** jadi fokus utama — tidak perlu terpaku pada template bawaan.
- 🌐 Pendekatan yang lebih segar dibanding generator statistik GitHub lain.
- 🚨 Tampil beda di komunitas developer dengan GIF yang eye-catching.
- 📦 Kontrol tingkat tinggi atas estetika README lewat fungsi-fungsi simulasi terminal.

## ⚙️ Prasyarat

1. Python >=3.9
2. [FFmpeg](https://ffmpeg.org/download.html)
3. [GitHub personal access token](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens#creating-a-fine-grained-personal-access-token) (Opsional)
4. [ImgBB API key](https://api.imgbb.com/) (Opsional)
